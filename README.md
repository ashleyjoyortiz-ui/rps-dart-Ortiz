How to Run the Program

Follow these steps to run the Rock, Paper, Scissors game

- Install Dart: Make sure Dart is installed on your computer.

- Open the Project: Open the folder containing "rock_paper_scissors.dart" in Visual Studio Code.

- Open the Terminal: In VS Code, click Terminal and select New Terminal.

- Check the Dart Installation: Type "dart --version" in the terminal and press Enter.

- Run the Program: Type the following command and press Enter:
   
   dart rock_paper_scissors.dart

- Play the Game: Follow the instructions displayed in the terminal to play Rock, Paper, Scissors.

- View the Result: The program will display whether you win, lose, or draw.
